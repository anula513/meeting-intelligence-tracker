# Definition of Done

## A story is done when
- It works on the test transcripts
- It has been tested with at least one edge case
- Code is committed with a clear message
- Any relevant doc is updated

## Sprint 0 is done when
- Documents 01-07 are in the repo's docs folder
- Repo is live with README, CLAUDE.md, and setup files
- Virtual environment and .env work, and .env is confirmed gitignored
- Sprint 1 plan is written

## Sprint 1 is done when
- Extractor returns valid JSON on all sample and eval transcripts
- Every source quote is verified by code
- 15 transcripts are hand-labeled and scripts compute precision, recall, and invented-owner count
- Baseline report is written, with the 3 worst failures analyzed
- Sprint review and retrospective are written

## Sprint 2 is done when
- Multiple meetings can be stored and queried
- Answers include citations
- 20-question retrieval eval is complete and documented
- Sprint review and retrospective are written

## Sprint 3 is done when
- Demo is deployed and the link works
- README includes architecture diagram, setup steps, and results
- 2-3 minute demo video is recorded
- Final report is written
- Resume bullets use real measured numbers
